# Exercise reference corpus

`PMC10801605.xml` is the Europe PMC full-text XML of
*Optimizing Resistance Training Technique to Maximize Muscle Hypertrophy:
A Narrative Review* (2024), DOI 10.3390/jfmk9010009, published under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
[Publication and attribution](https://pmc.ncbi.nlm.nih.gov/articles/PMC10801605/).
Downloaded 2026-11-13 from
https://www.ebi.ac.uk/europepmc/webservices/rest/PMC10801605/fullTextXML.
SHA-256: `fc15ccb56e8cf0fe965e440fa18c167ffbe0953a4603e468cfe97fe69c5711fd`.

The paper addresses general technique and hypertrophy; it is not an exhaustive
catalogue of exercise instructions or a source for treating pain.
`scripts/extract_exercise_reference.py` extracts paragraph text and section
metadata for indexing.

## Local vector indexes

`exercise-vectors.sqlite3` is a locally generated sparse, L2-normalized TF-IDF
index built with `python3 backend/scripts/vectorize_exercise_references.py`.
It contains 34 article paragraphs, 876 Free Exercise DB records, and 13,240
LogPress exercise-language records. No images are included. Each row stores its
source, identifier, language, section, URL, text and compressed vector; source
hashes and TF-IDF vocabulary are stored in the database. Rebuild after source
changes. This index is the source snapshot for semantic indexing.

`exercise-semantic.sqlite3` is generated by
`python3 backend/scripts/build_semantic_exercise_index.py` from the preceding
index and the two additional articles. The current index contains 14,227
passages: 14,150 from the original index and 77 from those articles. The script uses Ollama's multilingual
`embeddinggemma:300m-qat-q4_0` model, persists per-batch progress to a partial
file, records source hashes and model identity, and replaces the completed index
atomically. Set `EXERCISE_EMBEDDING_URL` to the Ollama service and
`EXERCISE_EMBEDDING_MODEL` to the model used for both building and querying.
The chat searches normalized semantic vectors locally and asks the configured
chat provider to explain evidence in Brazilian Portuguese. Ollama translations
use the dedicated `translategemma:4b` model; configure it with
`EXERCISE_TRANSLATION_MODEL` and pull it into the same Ollama model volume before
use. It checks that each statement references an actual retrieved passage and
quotes an existing excerpt. A semantic similarity check rejects clearly
unrelated claims and translations; these checks do not prove that a claim
follows from its excerpt or that a translation is accurate.
Set `EXERCISE_VECTOR_INDEX` to select another index path and list source file
names in `EXERCISE_REVOKED_SOURCES` to immediately exclude them. Source hashes
are checked where the original files are available. Provider failure, index
failure or insufficient similarity produce a controlled response.

The downloaded LogPress snapshot has no Portuguese records. The semantic model
supports cross-language search but the available evaluation is limited and it
may miss queries or conflate exercise variations. Neither index establishes
accuracy, rights clearance or safety; unresolved provenance issues remain
relevant to production use. The embedding model is subject to its publisher's
[Gemma terms](https://ai.google.dev/gemma/terms).
